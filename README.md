# Web Application Development Starter

This starter follows the assignment brief: React frontend, Express REST API, and MySQL database.

## Project structure
- `frontend/` — React + Vite application
- `backend/` — Express API and MySQL connection
- `database/schema.sql` — database and table definitions

No `node_modules` folders are included. We will install dependencies and run the project together, one command at a time.

## Requirements
- Node.js (LTS)
- MySQL Server (or XAMPP with MySQL)
- A code editor such as Visual Studio Code

## Important
Do not run every command at once. We will go through setup step by step and check each result before moving on.
